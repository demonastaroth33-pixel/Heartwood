## 1. Intent Map

### 1.1 Goals implied across the corpus

- **G1 — Fitness domain completeness.** A full fitness domain is added (workouts, exercise_sets, seeded exercises, muscle hierarchy, phases, body metrics, nutrition, deloads, cardio, records vault) reusing the existing entity+event pattern (L001–L017, L022–L037).
- **G2 — One derived math owner.** Every derived stat has exactly ONE H3 owner function; pace/rolling/target math is shared (paceVerdict, rollingAvgWeight, deriveMacros, strengthSnapshot, est1RM) (L038–L039, L084, L144–L145, L165, L168, L244; TEMP 855–871, 2343–2350).
- **G3 — One surface, not two.** Weekly review merges into the Sunday check-in; week recap = glance + verdict; dashboard "Today" fuses briefing + habits + capture (L099, L101, L154, L243; TEMP 2323–2341, 2362–2393).
- **G4 — True cross-device sync before multi-device phases.** A general entity-sync plane is a REQUIRED new milestone ahead of P2.5 (L043–L044, L096, L157, L191; TEMP 92–120, 1783–1786).
- **G5 — Canonical-file-elsewhere for achievements.** v2 = THE WHAT, spec = THE WHEN, ledger = THE WHY; DOCS-PASS RULES govern Gamification.md drafting (L176–L177, L136; TEMP 982–1007).
- **G6 — Coach as one index.** The Coach Consolidated Functionality Map is the master reference for every Coach capability; rule catalog is a separate deferred session (Coach map, TEMP 2439–2597; L171, L190).
- **G7 — Process discipline.** Ledger-first workflow; declined/skipped/rejected items stay dead; draft rows carry explicit verdicts (TEMP 817–826; L052, L054, L058, L060–L061, L064, L068, L216, L265, L270, L248).

### 1.2 Non-goals implied across the corpus

- No new subsystem for pace math — Analytics → Rule → Reflection pipeline only (L005; TEMP 20–23).
- No AI required — journal parsing deferred; auto-assort is rule-based/offline; Coach works without paid APIs (L008, L018, D004).
- No push notifications — on-open catch-up only (L093, L126, audit-C1, D018).
- No XP for logging, streak markers, or achievements; reviews give no XP (L016, L094, L173, L176, L227).
- No resurrection of rejected/skipped features: I6, I8, N3, N5, N6, N8, F3, Part-B #2/#3/#4/#7, RPE, FUT-1 (L052, L054, L058, L060–L061, L064, L068, L216, L265, L270).

- No invented IDs or features during the docs pass — E-clash #2 is a gap, do not invent (ledger 386–391; census §17); "no new inventions during the docs pass" (TEMP 1006–1007).
